🔒Privacy Policy

Last updated: February 6, 2026

🛡️ RocketWhisper Privacy Protection

RocketWhisper is a completely offline speech recognition app. Voice data is never sent to external servers -- all processing is performed entirely on your computer.

1. Information We Collect

RocketWhisper only collects and stores the following information:

  • Settings: App settings (hotkeys, model selection, etc.) are saved to local files
  • License information: During license activation only, we communicate with our server to verify license key validity

Information we do NOT collect:

  • Voice data
  • Recognized text
  • Usage statistics or analytics
  • Personally identifiable information

2. Voice Data Processing

RocketWhisper's speech recognition is performed entirely locally as follows:

  • Microphone input is processed exclusively on your computer
  • The speech recognition engine (Whisper) runs locally
  • Voice data is never transmitted over the internet
  • Recordings are saved as temporary files and deleted after recognition is complete

3. AI Processing Features

When using AI Command Mode or AI Processing features:

  • Text may be sent to the AI provider configured by the user (OpenAI, Anthropic, Google, etc.)
  • Only recognized text is sent -- voice data is never transmitted
  • When using local LLMs (Ollama, etc.), all processing remains entirely local
  • Data is sent to AI providers only through explicit user actions

4. License Activation

During license activation only, the following information is sent to our server:

  • License key
  • Hardware ID (an anonymized identifier for your PC)

This information is used solely to verify license validity and is not used for any other purpose.

5. Data Storage Locations

All data is stored exclusively on your computer:

  • Configuration files: ~/.config/RocketWhisper/
  • Whisper models: ~/.local/share/RocketWhisper/Models/
  • Temporary files: /tmp/ (deleted at session end)

6. Third-Party Disclosure

We do not provide your information to third parties, except as required by law.

7. Security

RocketWhisper is designed with security as a priority:

  • All processing is performed locally with no unnecessary external communication
  • License activation communication is protected by HTTPS (TLS encryption)
  • Temporary files are properly deleted

- `index.html` - メインページ（機能紹介、ダウンロード、動作環境）
- `help.html` - ヘルプページ（インストール方法、使い方、トラブルシューティング）

- `support.html` - サポート・お問い合わせ
- `css/style.css` - スタイルシート

## RocketWhisperについて

RocketWhisperは、完全オフラインで動作する高精度音声認識アプリケーションです。

### 主な特徴

- OpenAI Whisperによる高精度音声認識
- 完全ローカル処理（音声データは外部に送信されません）
- NVIDIA GPU（DGX Spark, Jetson）でCUDA加速対応
- Ubuntu, Debian, Fedora, Arch Linux対応
- ARM64 / x86_64アーキテクチャ対応

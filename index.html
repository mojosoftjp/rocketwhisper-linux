📚 3ステップで使い始める

1

依存パッケージをインストール

sudo apt install pulseaudio-utils xdotool xclip ffmpeg

Ubuntu/Debian系。Fedoraはdnf、Archはpacmanを使用。

2

AppImageをダウンロード＆実行

chmod +x RocketWhisper-*.AppImage
./RocketWhisper-*.AppImage

インストール不要。ダウンロードして実行するだけ。

3

ホットキーで録音開始！

F8 録音開始/停止

押して話す。もう一度押して認識。それだけ。

⚠️

Wayland環境をお使いの方へ

Waylandでは以下の機能に制限があります：

  • グローバルホットキー（ydotoolが必要、root権限が必要な場合あり）
  • 自動貼り付け（wl-clipboardが必要）
  • AIコマンドモード（クリップボード制限の影響）
  • アプリ別処理（ウィンドウ検出に制限）
追加パッケージ： sudo apt install ydotool wl-clipboard

💡 X11セッションでログインすると全機能が利用可能です

❓ よくある質問

Q Windows版とライセンスは共通ですか？
A はい、共通です。Windows版で購入したライセンスはLinux版でもそのまま使えます。
Q GPUがなくても使えますか？
A はい、CPUでも動作します。GPUがあれば自動的にCUDA加速が有効になりますが、なくても問題なく使えます。
Q Waylandで全機能使えますか？
A Waylandでは一部機能に制限があります。全機能を使うにはX11セッションでログインしてください。
Q AppImageの展開は必要ですか？
A いいえ、そのまま実行できます。chmod +xで実行権限を付与すればOKです。FUSEがない環境では--appimage-extractで展開することもできます。
